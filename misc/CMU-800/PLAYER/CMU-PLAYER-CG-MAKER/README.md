## 1. Python をインストールする
### Windows
1. 公式サイトから Python をダウンロード  
   https://www.python.org/downloads/
2. インストーラを起動
3. **「Add Python to PATH」 にチェックを入れる（重要）**
4. 「Install Now」を選択

### macOS
Homebrew がある場合：
```
brew install python
```
---
## 2. bmpファイルを用意する。
取り込みたいBMPファイルをツールと同じフォルダに格納してください。
---

## 3. スクリプトを実行する

コマンド プロンプト（または PowerShell）でフォルダに移動：
```
cd フォルダのパス
```
Usage:
  python cpmake_v1.py<br>
  を実行後、画像ファイルを指定してください。  

なお、下記ファイルはすべて同じフォルダにおいて実行してください。  
cpmake_v1.py  
input-template.bin  
bmpデータ  
```
