MID2CMU GUI - MIDI を CMU-800 (MZT) に変換

■ 使い方
  MIDIファイルをウィンドウにドラッグ＆ドロップ → 役割を確認 → 「変換して保存」
  役割は自動判定です。違う場合は行を選んで「指定」を変えてください。

■ 割り当てルール
  CH1  メロディ   : 音量(ベロシティ×CC7×CC11)・単音性・音高などから自動選択。同時発音は最高音
  CH2  ベース     : 音色がベース系(GM 32-39)のチャンネル。同時発音は最低音
                    ベースが鳴っておらずコードCHが全て埋まっている時、あふれた音の最低音をCH2へ
  CH3-6 コード    : 各時刻で音量の大きい順に1音ずつ割り当て。CHが空けば次候補を途中から割り当て
  CH7  ハモリ     : メロディと同じタイミングで動く単音パートを自動検出
                    (無い場合は CH7 もコードに使用。オプションで解除可)
  CH8  パーカッション or コード
                  : MIDI CH10 のうちリズム用7音に割り当てられない音(カウベル等)を単音で出力。
                    8打未満ならコードに使用(オプションで固定可)
  CH0/CH9 リズム  : mid2cmu_v1.10.py と同じ変換(CH0=パターン, CH9=配置)

分解能(1ST=1/24四分音符, 1小節=96ST)、テンポ可変機能、MZTヘッダは v1.10 と同じです。

■ MZTにする前に修正したい場合(割り当て済みMIDI)
  「変換して保存」で ○○.mzt と一緒に ○○_cmu.mid も出力されます(「割り当てMIDIだけ保存」ボタンならMIDIのみ)。
    MIDI CH1〜8 = CMU CH1〜8 (トラック名 CMU-CH1 など) / MIDI CH10 = ドラム
  1) ○○_cmu.mid をDAW等で開いて、音の移動・削除・追加を行い、MIDIで書き出す
     (CH1〜8は単音になるよう編集。同時発音が残る場合は最高音だけ使われます)
  2) 書き出したMIDIをこのツールにドロップ
     → 割り当て済みMIDIとして自動判定され、再割り当てなしでそのままMZTになります
  ※トラック名がDAWで消えて自動判定されない場合は、「割り当て済みとして直接変換」にチェックを入れてください。
  ※○○_cmu.mid が既にある場合は上書き確認が出ます。編集中のファイルは別名で保存しておくと安全です。
  ※CH8がパーカッションの時、CH8のノート番号はドラム音のノート番号(カウベル=56など)です。
