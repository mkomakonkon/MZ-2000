# MZ-2000 VOCALUINO4CMU (Rev.0.2)

MZ-2000の拡張I/Oポートに接続し、CMU-800動作時にやり取りされる制御信号を傍受・処理することで、**音階に合わせた歌唱（音声合成）**や**MIDI信号の送出**を行うための拡張ボードです。

---

## 1. 基本機能と構成

### 基本機能
CMU-800 動作時にやり取りしている信号を傍受し、以下の動作をします。
* 希望のCHの音階で歌を歌う（ATP3011R4-PU必須）
* 希望のCHの音階でMIDI信号を送出する

### 追加機能
テンポクロックを取り込むことで自分自身をCMU-800に化かすことができます。
テンポクロックは以下のいずれかの方法で生成します。
* 外部入力端子（CLK-IN1）から CMU_CLOCK_MODULE のクロックを取り込む
* 基板内の Arduino（A1）でテンポクロックを自己生成する

---

## 2. 入出力インタフェースと設定端子

1. **カードエッジコネクタ (J1)**: MZ-2000の拡張I/Oポート4に直接実装可能。
2. **J2**: 2×22のピンヘッダを使い、`VOCALUINO4CMU-ADP` をはんだ付けすることで CMU-800 インタフェースにすることが可能。（CMU-800のI/F 基板と 50pin のフラットケーブルで接続可能。）
3. **Arduino Nano ソケット (A1, A2)**: 
   * **A1**: 内部クロックモジュールとして動作させる場合、シリアルモニタ経由でテンポ指定が可能。VOCALUINOとして使用する場合、USB経由で歌詞データ込みのスケッチを書き込む。
   * **A2**: MIDIインタフェースとして使用する場合、CHのアサインなどのスケッチをUSB経由で書き込む。VOCALUINOとして使用する場合、USB経由で歌詞データ込みのスケッチを書き込む。
4. **発音LED (V1〜V4)**: ATP3011R4-PUが発声時（/PLAY端子アクティブ時）に点灯。
5. **CLK-IN1**: CMU_CLOCK_MODULE のクロックを取り込むための外部入力端子（CMU-800の CLOCK OUT も入力可能）。
6. **JP1**:
   * **CMU-800と連動する場合**: N/A（オープン）
   * **内部クロックを生成してCMU-800に化かす場合**: 内部クロック使用側をショート
   * **外部クロックを使用してCMU-800に化かす場合**: 外部クロック使用側をショート
7. **J8**:
   * **CMU-800と連動する場合**: オープン
   * **CMU-800と連動しない場合**: ショート
8. **SW1**: Arduino Nano と ATP3011R4-PU の手動リセットスイッチ。
9. **J6**: MIDI出力端子（DIN 5ピン）。
10. **OUT1**: ATP3011R4-PU の音声出力端子（3.5mmステレオミニジャック等）。

---

## 3. スケッチ（制御プログラム）の解説

### Arduino Nano (A1) 用スケッチ

* **02_VOCALUINO4U_seisyun.ino**
  * **概要**: MZ-2000の CMU-800 動作時にやり取りされる信号（アドレスやゲート、音階データ VD[5:0] など）を、基板上の 74LS259 エミュレート処理を介して傍受し、音声合成 LSI「ATP3011R4-PU」に歌わせるためのスケッチ。
  * **主な機能・特徴**:
    * メロディの音階データ（VD値）を AquesTalk 用のピッチに変換し、I2C経由で ATP3011R4-PU を発音させる。
    * ピン変化割り込み（PCINT）を利用して、Qエッジの検出イベントをリングバッファへ安全に格納・処理する設計。
    * PIN_VOICE_RST（D9）の立ち下がりを検知すると、歌詞インデックスをリセットして頭から再生し直す機能を持つ（リズムパートの bit0 制御などと連動）。
    * FLASHメモリ（PROGMEM）に歌詞データを保存し、SRAM容量を節約。
* **CLOCK_UNIT2.ino**
  * **概要**: Arduino Nano (A1) を「内部クロック生成ユニット」として動作させるためのスケッチ。CMU-800 と連動しない環境などで、MZ-2000 側にテンポクロックを供給する場合に使用する。
  * **主な機能・特徴**:
    * Arduino IDE のシリアルモニタ（ボーレート: 115200bps）から、任意の BPM を数値で指定・変更できる。
    * Timer1 の CTC モード（OC1A トグル出力）を利用し、D9 ピンから正確な 50% デューティのハードウェアクロックを出力する。
    * クロック周波数は BPM / 2.5 の計算式で自動算出され、BPM=0 を指定した場合はクロック出力を停止する。

### Arduino Nano (A2) 用スケッチ

* **MIDI_MULTI_LOVE_REASON_WHY.ino**
  * **概要**: Arduino Nano (A2) を MIDI インタフェースとして動作させ、MZ-2000 の CMU-800 信号を MIDI メッセージ（ノートオン/オフ、プログラムチェンジ、コントロールチェンジ等）に変換・送出するためのスケッチ。
  * **主な機能・特徴**:
    * メロディ用として CH1〜CH8 (Q0〜Q7) の信号を監視し、対応する MIDI チャンネルおよびノート番号で発音・停止信号を出力する（ハードウェアシリアル D1 ピンから 31250bps で送信）。
    * ドラムパート用として 7 本の独立した入力ピン（D9〜D13, A6, A7）の立ち下がりエッジを監視し、指定された GM ドラムのノート番号を MIDI チャンネル 10 でトリガーする。
    * 各チャンネルの GM 楽器番号やボリューム、ドラムの初期設定を柔軟に変更・アサイン可能。

# MZ-2000_VOCALUINO4CMU

MZ-2000 および Roland CMU-800 システムに向けた音声合成（歌唱）機能および MIDI インタフェース拡張ボードです。CMU-800 のバス信号を傍受・エミュレートすることで、リアルタイムでの音声合成発音や MIDI 送出、ならびにテンポクロック生成による擬似 CMU-800 動作を実現します。

## 1. 概要と基本機能

### 基本機能

CMU-800 動作時にやり取りされるバス信号を傍受し、以下の動作を行います。

* **音声合成歌唱**: 音声合成 LSI（ATP3011R4-PU）を使用し、指定したチャンネルの音階に合わせて歌詞を歌わせます。

* **MIDI 信号送出**: CMU-800 の演奏データ（メロディ・コード・ドラム）を標準 MIDI 信号に変換して外部音源へ送出します。

### 追加機能

テンポクロックを取り込むことで、本ボード自身を CMU-800 のクロック源（擬似 CMU-800）として動作させることができます。テンポクロックの供給方法は以下の 2 通りから選択できます。

* 外部入力端子（CLK-IN1）から CMU_CLOCK_MODULE 等のクロックを入力。

* 基板上の Arduino Nano（A1）でテンポクロックを自己生成。

### 前提条件・必要環境

* **音声合成発音時**: 音声合成 LSI **ATP3011R4-PU** が必須です。

* **クロック自己生成時**: Arduino IDE のシリアルモニタ等（115200 bps）から BPM 設定を行います。

* **MIDI 演奏時**: 外部 MIDI 音源および 5 ピン DIN MIDI ケーブルが必要です。

## 2. 入出力インタフェースと設定端子

| 番号 | 名称 | 説明 | 
| ----- | ----- | ----- | 
| **①** | **カードエッジコネクタ (J1)** | MZ-2000 の拡張 I/O ポート 4 に直接実装・接続します。 | 
| **②** | **J2 ピンヘッダ** | 2×22（44ピン）のピンヘッダ。変換サブ基板 `VOCALUINO4CMU-ADP` を実装することで、CMU-800 標準ピンアサインインタフェースへ拡張可能です。 | 
| **③** | **Arduino Nano ソケット (A1, A2)** | 2基の Arduino Nano（A1, A2）を実装可能。クロック生成、音声合成制御、MIDI 送出などの処理を分担します。 | 
| **④** | **LED (V1〜V4)** | ATP3011R4-PU の発音時（`/PLAY` 端子アクティブ時）に点灯するステータス表示 LED です。 | 
| **⑤** | **CLK-IN1** | CMU_CLOCK_MODULE や CMU-800 の `CLOCK OUT` からクロックを取り込むための外部入力端子です。 | 
| **⑥** | **JP1 (クロック選択ジャンパ)** | クロックの供給元（内部生成 / 外部入力）を選択します。 | 
| **⑦** | **J8 (連動モードジャンパ)** | 実機 CMU-800 と連動させるか、本ボード単体（擬似 CMU-800）で動作させるかを切り替えます。 | 
| **⑧** | **SW1 (手動リセット)** | Arduino Nano および ATP3011R4-PU を手動でリセットするスイッチです。 | 
| **⑨** | **J6 (MIDI OUT)** | 5 ピン DIN コネクタによる標準 MIDI 出力端子です。 | 
| **⑩** | **OUT1 (音声出力)** | ATP3011R4-PU から合成された音声信号が出力されるオーディオジャックです。 | 

## 3. 他機種（MZ-2000 以外）での利用：CMU-800 変換基板

本ボードは MZ-2000 の拡張 I/O ポート（J1）に直接挿して使用する設計になっていますが、**「CMU-800ピンアサイン変換基板（`VOCALUINO4CMU-ADP`）」**を接続することで、**MZ-2000以外のCMU-800対応機種(PC-8801シリーズ、FM-7シリーズ等)**でも本ボードの機能（歌唱・MIDI送出・クロック生成）を利用可能です。

### 接続・使用方法
1. 本ボード上の **J2**（2×22 ピンヘッダ）に変換サブ基板 `VOCALUINO4CMU-ADP` をはんだ付け・実装します。
2. 各機種用 CMU-800 インタフェースボードと `VOCALUINO4CMU-ADP` の間を **50pin フラットケーブル** で接続します。

これにより、MZ-2000 以外の環境でも本ボードを「CMU-800 互換の音声合成・MIDI パフォーマー」として活用できます。

## 4. 動作モードとジャンパ設定

使用する環境や目的に応じて、ジャンパピン（JP1, J8）を以下のように設定してください。

### Mode A: CMU-800 連動モード

実機 Roland CMU-800 と接続し、CMU-800 側の動作・クロックに完全同期して歌唱や MIDI 送出を行うモードです。

* **JP1**: N/A（未使用）

* **J8**: **オープン**

### Mode B: 内部クロック生成モード（CMU-800 エミュレーション）

CMU-800 実機を使用せず、Arduino（A1）で生成した BPM クロックを使い、ボード単体を CMU-800 として動作させるモードです。

* **JP1**: **内部クロック使用側をショート**

* **J8**: **ショート**

### Mode C: 外部クロック同期モード（CMU-800 エミュレーション）

CMU-800 実機を使用せず、外部クロックモジュール（CLK-IN1）からの信号に同期して単体動作させるモードです。

* **JP1**: **外部クロック使用側をショート**

* **J8**: **ショート**

## 5. Arduino Nano スケッチ（プログラム）説明

### 【A1 用スケッチ】

#### 1. `02_VOCALUINO4U_seisyun.ino`

* **概要**:
  MZ-2000（または変換基板経由の CMU-800 バス）の動作時にやり取りされる信号（アドレス `CHA`〜`CHC`、ゲート `/G`, `GATE`、音階データ `VD[5:0]`）を基板上の 74LS259 エミュレート処理を介して傍受し、音声合成 LSI（ATP3011R4-PU）に歌わせるためのスケッチです。

* **主な機能・特徴**:

  * メロディの音階データ（VD値）を AquesTalk 用のピッチパラメータに変換し、I2C 経由で ATP3011R4-PU を駆動します。

  * ピン変化割り込み（PCINT）を利用し、Q エッジの検出イベントをリングバッファへ格納することで高速・安全な信号処理を実現しています。

  * `PIN_VOICE_RST`（D9）の立ち下がりを検知すると、歌詞インデックスをリセットして先頭から再演奏する機能を搭載（※配線・運用により調整可能）。

  * 歌詞データ（文字列テーブル）は Flash メモリ（`PROGMEM`）上に保持し、SRAM 容量を節約しています。

#### 2. `CLOCK_UNIT2.ino`

* **概要**:
  Arduino Nano（A1）を「内部クロック生成ユニット」として動作させるスケッチです。CMU-800 が無い環境等で MZ-2000 側にテンポクロックを供給します。

* **主な機能・特徴**:

  * Arduino IDE のシリアルモニタ（115200 bps）から任意の BPM 数値（例: `120`, `135.5`）を入力することでテンポを動的に変更できます。

  * Timer1 の CTC モード（OC1A トグル出力）を利用し、D9 ピンから 50% デューティの正確なハードウェアクロックを出力します。

  * クロック周波数は $\text{周波数 (Hz)} = \text{BPM} / 2.5$ の計算式で自動算出されます（BPM=0 で停止）。

### 【A2 用スケッチ】

#### 1. `MIDI_MULTI_LOVE_REASON_WHY.ino`

* **概要**:
  Arduino Nano（A2）を MIDI インタフェースとして動作させ、CMU-800 のバス信号を標準 MIDI メッセージ（ノート ON/OFF、プログラムチェンジ、コントロールチェンジ等）にリアルタイム変換して送出するスケッチです。

* **主な機能・特徴**:

  * メロディ・コード用として CH1〜CH8（Q0〜Q7）の信号を監視し、対応する MIDI チャンネルおよびノート番号で発音・停止信号を送信します（TX/D1 ピンから 31250 bps 出力）。

  * ドラムパート用として 7 本の独立入力ピン（D9〜D13, A6, A7）の立ち下がりエッジを監視し、指定された GM ドラムのノート番号を MIDI 通信（CH10）でトリガーします。

  * 各チャンネルの GM 楽器番号（Program Change）や初期ボリューム（Control Change #7）をコード内で柔軟にアサイン可能です。

#### 2. （補足）A2 への `02_VOCALUINO4U_seisyun.ino` 流用について

Arduino Nano（A2）側のソケットに挿入した ATP3011R4-PU を使用して歌唱させる場合、`02_VOCALUINO4U_seisyun.ino` をそのまま流用・書き込みすることが可能です。

* A1/A2 で同時に歌唱スケッチを使用する場合は、それぞれのコード内の定数 `V_CH`（担当チャンネル）を変更（例: A1 を CH1、A2 を CH2）することで、マルチパート（デュエット等）の音声合成歌唱が実現できます。

## 6. システム拡張性と運用ノート

1. **A1 / A2 の役割分担パターン**

   * **標準構成（歌唱 ＋ MIDI）**:

     * A1: `02_VOCALUINO4U_seisyun.ino`（音声合成歌唱）

     * A2: `MIDI_MULTI_LOVE_REASON_WHY.ino`（外部 MIDI 音源演奏）

   * **スタンドアロン演奏構成（内部クロック ＋ 歌唱）**:

     * A1: `CLOCK_UNIT2.ino`（BPM クロック供給）

     * A2: `02_VOCALUINO4U_seisyun.ino`（音声合成歌唱）

   * **ツインボーカル構成**:

     * A1: `02_VOCALUINO4U_seisyun.ino`（パート 1）

     * A2: `02_VOCALUINO4U_seisyun.ino`（パート 2）

2. **配線および設定上の注意点**

   * D9 ピンは `CLOCK_UNIT2.ino` ではクロック出力、`02_VOCALUINO4U_seisyun.ino` ではリセット入力（`PIN_VOICE_RST`）、`MIDI_MULTI_LOVE_REASON_WHY.ino` ではドラム入力ピンとして使用されます。書き込むスケッチと基板のジャンパ設定（JP1/J8）が合致しているか確認してください。

   * I2C アドレスの重複を避けるため、基板上に複数の ATP3011R4-PU を実装する場合は、LSI ごとにアドレス設定（`0x2E`, `0x2F` 等）が正しく行われていることを確認してください。
